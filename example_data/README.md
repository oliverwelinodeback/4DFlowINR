# Example data

`example_LR.h5` is an example input dataset for testing the 4DFlowINR reconstruction workflow.

The file is stored using
[Git Large File Storage](https://git-lfs.com/).

## Download

Install Git LFS before cloning the repository:

```bash
git lfs install
git clone https://github.com/oliverwelinodeback/4DFlowINR.git
cd 4DFlowINR
